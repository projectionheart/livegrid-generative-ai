How it connects + rollback

Phone → Mobile Bridge → LiveGrid controls and OSC → TouchDesigner. Video still travels from LiveGrid to TouchDesigner through Spout. This page generates no AI video.

In TouchDesigner add an OSC In CHOP, enable Active, and set Network Port to 9000. Map livegrid/x and livegrid/y to your effect parameters. See the release guide for every channel.

To roll back locally, close the bridge and open the original LiveGrid controller at port 8765. This add-on does not replace the engine or its original interface. The release includes a repository checkpoint for reverting the published update.
